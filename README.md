# Mahabaleshwar Taxi Service Website

This is the improved, conversion-optimized website for **Aryan Tours & Travels**, offering Mahabaleshwar sightseeing, outstation cabs, and local drops.

## 🚀 Key Features Added
- **Full-Day Sightseeing Package:** A new comprehensive tour covering Mahabaleshwar & Panchgani for ₹3000.
- **Offer Your Rate:** A budget-friendly feature allowing customers to negotiate prices.
- **Trust & Authority:** Explicit "Govt. Registered" and "Union Member" badges.
- **SEO Optimization:** Enhanced meta tags and Schema markup for local search dominance.

## 📂 Project Structure
- `index.html`: The main landing page requiring zero dependencies.
- `mahabaleshwar-hero.jpg`: High-quality hero image.
- `mahabaleshwar.jpg`: Secondary optimized image.
- `Aryan Tours Logo.png`: Brand logo.
- `sitemap.xml`: For Google Search Console indexing.
- `robots.txt`: Crawler instructions.

## 🛠️ How to Deploy (GitHub Pages)
1. Commit and push all changes to the `main` branch.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Select `main` branch and `/root` folder.
4. Click **Save**.
5. Your site will be live at: `https://sunildanawale.github.io/Mahabaleshwartaxi/`

## 📱 Mobile & Performance
- The site is fully responsive and mobile-first.
- Sticky "Call" and "WhatsApp" buttons ensure high conversion rates on mobile devices.
- Schema markup is implemented for "TaxiService" and "LocalBusiness" to appear in Google Rich Results.
